# HamTech RTL Comander

A Windows receiver console for the **RTL-SDR Blog V4**, with a radio-style interface, live spectrum, waterfall and receiver audio.

**Current version: V17 — FM/NFM 25 kHz filter**

## Features

- Receive **AM, FM/NFM, WFM, USB, LSB and CW**.
- Large frequency display with mouse-wheel tuning and click-to-edit.
- Small yellow STEP button for changing tuning increments.
- Live spectrum with a black background and green trace.
- Fine waterfall display with blue background, light yellow signal highlights and
